## Инструкция к запуску

Открыть powershell в папке `main.py` и запустить команду. Воспринимаются как файлы внутри текущей папки, так и полные пути до них.
```
python main.py
```

В меню можно выбрать исходный файл и путь результата, переключить язык и включить отчёт. 
При вводе пути Enter оставляет текущее значение. Пункт `5` начинает обработку, пункт `0` закрывает меню. 
Имя файла без полного пути считается относительно текущей папки терминала.

Можно начать обработку сразу, для этого нужно передать пути при запуске питоновского файла.
```
python main.py "input.xml" "output.xml"
```

По умолчанию программа использует английский словарь, но также встроенным языком является русский.
При запуске программа создаёт папку `dictionary` в текущей папке терминала, если её ещё нет. Для использования под другие языки нужно создать словарь в папке `dictionary`, и при последующих новых запусках проги они подгружаются. Некорректные файлы пропускаются без сообщений.
Пример (шаблон) словаря `dictionary/de.json`.
```json
{
  "language_name": "Немецкий",
  "fruits": ["Apfel", "Birne", "Kirsche", "Pflaume", "Karotte"],
  "people": ["Lio", "Mira", "Taro", "Lina"],
  "surname": "er",
  "middle": "mann",
  "object": "Objekt",
  "substation": "Umspannwerk",
  "transformer": "Transformatorstation",
  "line": "Leitung",
  "point": "Schaltstation",
  "organization": "Unternehmen",
  "street": "Straße",
  "address": "Adresse",
  "voltage": "kV",
  "redacted": "[Entfernt]"
}
```

Либо можно при запуске напрямую указать словарь из папки через параметр.
```powershell
python main.py "input.xml" "output.xml" --language ru --dictionary "de.json"
```
Чтобы использовать словарь из другой папки, укажите его полный путь через `--dictionary "<путь>"`.
Если программа встретит неизвестное непустое текстовое поле, она остановится и укажет его название. Если `output.xml` уже существует, программа заменит его только после успешной проверки нового файла.

Чтобы рядом с выходным XML появился `output.report.json` с количеством объектов и временем обработки, добавь `--report`.
```powershell
python main.py "input.xml" "output.xml" --report
```

## Какие данные обезличиваются

- **Названия объектов и организаций.** Реальные названия заменяются вымышленными на основе названий фруктов и овощей. Тип объекта и напряжение, указанное в названии, сохраняются.
- **Персональные данные и контакты.** ФИО, адреса и электронная почта заменяются вымышленными значениями. При замене телефонов, ИНН, КПП, паспортных и инвентарных номеров сохраняются длина и разделители.
- **Идентификаторы объектов.** UUID и другие распознанные идентификаторы заменяются вместе со ссылками, чтобы сохранить связи между объектами.
- **Свободный текст.** Распознанные комментарии, описания и логи закрываются маской `[Redacted]`.
- **Вложения.** В поддерживаемых схемах маскируются подписи, обновляются ссылки и заменяется старое изображение предпросмотра. Проверенные картинки и звуки из `reviewed-media.json` сохраняются без текстовых метаданных. Непроверенные медиа и неподдерживаемые пакеты очищаются.

## Какие данные сохраняются

- Структура CIM XML, классы оборудования и связи между объектами.
- Координаты в исходном XML, геометрия и соединения внутри поддерживаемых схем.
- Технические параметры оборудования, например номинальное напряжение, сопротивление, единицы измерения и порядковые номера элементов.
- Технические справочники и названия географических регионов.
- Операции и константы в поддерживаемых формулах. Имена переменных при необходимости переименовываются согласованно.

## Как работает программа

Перед обработкой программа читает исходный файл блоками и вычисляет его отпечаток SHA‑256. От него зависит последовательность всех замен.

1. Первый проход по структуре XML собирает идентификаторы объектов, категории абонентов и имена переменных из формул. Каждому идентификатору назначается новый UUID. Соответствия хранятся во временной SQLite-базе рядом с выходным файлом.
2. Второй проход обрабатывает по одному объекту. Ссылки получают те же UUID, что и объекты, на которые они указывают. В названия подставляются фрукты или овощи и порядковые суффиксы. Для физлиц программа подбирает вымышленные имя, фамилию, отчество, улицу и почту. При замене номеров сохраняются длина и разделители.
3. Программа повторно читает результат, сверяет его с записанными данными и только после проверки сохраняет готовый XML. Временная папка удаляется при штатном завершении или обработанной ошибке. При принудительном завершении процесса папка `cim-work-*` может остаться на диске и содержать исходные значения.

Правила для полей находятся в `field_rule`, генерация замен — в `make_name`, `make_person` и `make_number`. В `process` собраны этапы чтения, записи и проверки. Правила рассчитаны на предоставленный экспорт CIM. Если встретится неизвестное текстовое поле модели, программа сообщит его название и остановится. Комментарии и описания удаляются. Для формул сохраняются операции и технические параметры, а имена переменных согласуются с определениями.
В поддерживаемых пакетах схем программа маскирует подписи и пользовательские поля, обновляет ссылки на объекты и оставляет геометрию и связи внутри схемы. Старое растровое превью заменяется прозрачным, чтобы исходные подписи не остались в нём. Пакеты с неподдерживаемыми компонентами, например со скриптами или дополнительными ресурсами, очищаются целиком. По отчёту, если включить опцию его вывода, можно увидеть, сколько схем сохранено и сколько очищено.
Файл `reviewed-media.json` рядом с `main.py` содержит проверенные пиктограммы и короткие сигналы из исходной выгрузки. Программа подставляет их копии без текстовых метаданных только при совпадении отпечатка вложения. Если файл со списком отсутствует, обычные изображения и аудио очищаются. Для обработки схем этот список не нужен.
